# open-ugv
A collection of 3D printable parts, resources and software to help you build your first Unmanned Ground Vehicle.

## Guides

> [!NOTE]
> Use all guides at your own risk. Always follow safety precautions when working with tools, materials and power sources.

### [Getting Started With Aluminum Extrusions (Hackaday)](https://hackaday.com/2021/05/25/getting-started-with-aluminum-extrusions/)
A very comprehensive introduction to working with aluminum extrusions, including how to cut them, join them, and use them in projects.
